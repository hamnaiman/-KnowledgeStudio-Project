How this assistant works

Documents are read and split into overlapping token chunks. A sentence-transformer converts each chunk into a 384-dimensional embedding. ChromaDB stores the vectors and source text locally. Questions are embedded with the same model; the three nearest chunks are retrieved using cosine distance and passed to Groq.

Semantic search vs keyword search

Keyword search matches exact words or their lexical variants. Semantic search compares learned representations of meaning, so a question such as “How do I repeat an action?” can retrieve a passage about “loops” even without the same wording. Exact keyword search can be better for identifiers and unusual names. Semantic similarity is approximate, and neither method guarantees that a retrieved passage contains the answer.

Which prompt is best?

There is no measured winner until you run and rate the answers. Zero-shot is concise and simple. Few-shot demonstrates the desired response style and missing-information behaviour. Role-based prompting encourages an analyst's explanation style. The results table identifies the highest-rated technique for this document set; five questions and one run per prompt cannot establish a universal winner.
